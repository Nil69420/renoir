# Renoir

Renoir is a high-performance shared memory manager for zero-copy
inter-process communication, particularly suited for ROS2 and other
real-time systems.

## What Renoir does

- **Named shared memory regions** — file-backed and memfd
- **Cross-process topic pub/sub** — ring buffers live inside the topic's
  shared memory region, so processes attached to the same region share
  ring state and message data
- **Lock-free rings** — SPSC, SPMC, MPSC, MPMC patterns
- **Variable-size payloads** — inline ring storage or shared buffer pools
- **A stable C ABI** generated by cbindgen, plus C++ RAII and Python
  bindings
- **Real statistics** — end-to-end latency (average/peak), throughput,
  message counts, exposed through the C API and `renoir-cli topics`
- **Crash-safe region reuse** — advisory `flock()` liveness detection
  reinitializes regions orphaned by dead processes

## Honest scope

Renoir is pre-1.0. The items above are implemented and tested. Things that
are **not** shipped yet: a ROS2 middleware plugin (`rmw_renoir`),
request/response messaging, and real QoS semantics. The migration guides
state the real gaps rather than over-promising.
