# Language Bindings

Renoir ships three bindings:

- **[C](c.md)** — the primary interface, generated by cbindgen from the
  Rust FFI surface
- **[C++](cpp.md)** — an RAII wrapper over the C API
- **[Python](python.md)** — a PyO3 module in the `renoir-python` crate

All three wrap the same underlying Rust implementation; there is no
separate logic per language.
